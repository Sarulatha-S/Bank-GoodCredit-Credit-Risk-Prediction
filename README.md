# Bank GoodCredit – Credit Risk Prediction

## Project Overview
This project focuses on predicting customer credit risk using Machine Learning techniques. The objective is to identify customers with potential bad-credit behaviour based on historical account information, credit enquiries, and customer demographics.

## Business Objective
To develop a classification model that distinguishes between good-credit and bad-credit customers and helps support credit-risk assessment.

## Dataset Description
The project uses three datasets:
- Customer Account Data
- Customer Enquiry Data
- Customer Demographics Data

## Technologies Used
- Python
- SQL
- MySQL
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Project Workflow
1. Data extraction using SQL and Python
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Customer-level feature engineering
5. Dataset aggregation and merging
6. Machine Learning model development
7. Hyperparameter tuning
8. Weighted ensemble modelling
9. Model evaluation and risk decile analysis

## Machine Learning Algorithms
- Logistic Regression
- ExtraTrees Classifier
- XGBoost Classifier

## Model Evaluation
- ROC-AUC
- Gini Coefficient
- Risk Decile Analysis

## Final Results
- Test ROC-AUC: 0.6915
- Test Gini Score: 0.3831
- Project Benchmark Gini: 0.379
